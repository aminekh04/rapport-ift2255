# Risques & stratégies de mitigation

1. **Qualité des avis** (biais, troll) → Détection heuristique, votes d’utilité, regroupement par cohortes.
2. **Changements Planifium** (schéma/quota) → Tests de contrat, adaptateur versionné, fallback cache.
3. **Conformité légale** (Loi 25) → Privacy by design, DPIA, consentements, minimisation.
4. **Intégration complexe** (CSV/JSON/API) → Schéma canonique, pipelines idempotents, observabilité.
5. **Adoption** (faible usage) → Onboarding simple, partenariats TGDE/asso étudiante, feedback in-app.
