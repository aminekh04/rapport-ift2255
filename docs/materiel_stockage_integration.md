# Besoins matériels, stockage & intégration

- **Stockage** : Base relationnelle (agrégats, profils), index de recherche (texte, facettes).
- **Format** : CSV (résultats), JSON (avis), API (Planifium).  
- **Intégration** : Pipelines ETL planifiés (cron) + replays idempotents.
- **Sécurité** : chiffrement at-rest/en transit, gestion secrets, sauvegardes régulières.
