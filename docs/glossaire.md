# Glossaire
- **Planifium** : API UdeM pour programmes, cours, horaires.
- **Éligibilité explicable** : raison claire du statut (pré/co-requis, cycle, statut).
- **Agrégats académiques** : moyenne, inscrits, échecs par session.
- **Seuil n ≥ 5** : nombre minimal d’avis avant affichage.
- **Charge combinée** : estimation hebdomadaire des heures pour une combinaison.
- **Profil** : préférences, contraintes et objectifs d’un étudiant.
