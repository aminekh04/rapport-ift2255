
# Plateforme d’aide au choix de cours — Phase 1 (DIRO/UdeM)

## Brève description
Ce projet propose une **plateforme web** (rapport Phase 1) pour aider les étudiants du DIRO à **choisir leurs cours** de façon éclairée.  
Le rapport couvre : **cadre du projet**, **exigences** (fonctionnelles et non fonctionnelles), **cas d’utilisation** (dont 5 détaillés), **diagrammes d’activités**, **architecture C4 (L1–L2)**, **hypothèses/décisions**, **risques**, **glossaire**, **matériel & intégration** et **traçabilité**.  
La documentation est générée en **HTML** avec **MkDocs** (thème Material).

## Organisation du répertoire
